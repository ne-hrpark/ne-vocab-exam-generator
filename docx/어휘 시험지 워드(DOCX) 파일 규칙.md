# 어휘 시험지 워드(DOCX) 파일 규칙

시험지 워드 파일을 **단 수(1단·2단) × 글자 크기(9·11·13pt) × 문항 간격(5단계)** 조합으로 제작.  
아래는 각 파일이 따르는 규칙.

## 파일 구성

- 조합: **1단·2단 × 9·11·13pt × (매우좁게·좁게·보통·넓게·매우넓게)** = 총 **30개**
- 파일명: `어휘시험지_{단}_{크기}_{간격}.docx` (예: `어휘시험지_2단_11_보통.docx`)
- 폴더: `docx/1단/9·11·13`, `docx/2단/9·11·13`
- 글꼴은 **함초롬바탕**, 출제일/교재명은 가변.

---

## 1. 문항 간격 = 줄 간격 (글자 크기별)

문항 간격 5단계는 **줄과 줄 사이 간격**으로 표현했습니다.


| 문항 간격 | 9pt     | 11pt    | 13pt    |
| ----- | ------- | ------- | ------- |
| 매우좁게  | 9pt 고정  | 12pt 고정 | 14pt 고정 |
| 좁게    | 12pt 고정 | 14pt 고정 | 16pt 고정 |
| 보통    | 1.0배    | 1.0배    | 1.0배    |
| 넓게    | 1.15배   | 1.15배   | 1.15배   |
| 매우넓게  | 1.5배    | 1.5배    | 1.5배    |


- **보통·넓게·매우넓게**는 글자 크기에 **비례(배수)** 로 줬습니다. 글자가 커지면 줄 간격도 자동으로 넉넉해집니다.
- **좁게·매우좁게**는 **고정값(pt)** 으로 줬습니다. 배수로 하면 글자가 클수록 줄이 과하게 붙어 안 읽히기 때문에, 크기별로 최소 간격을 정해뒀습니다.

---



## 2. 단 수별 배치



### 1단

- 문제를 한 단에 위에서 아래로 쭉 배치.



### 2단

- **발문(※ …)은 가로 전체 폭**으로 놓습니다.
- 그 아래 **하위 문항만 좌·우 2단**으로 나눕니다. 왼쪽 단을 세로로 다 채운 뒤 오른쪽 단으로 넘어가서, **번호가 읽는 순서대로 이어집니다**(페이지를 넘어가도 번호가 꼬이지 않음). 좌우 분량은 비슷하게 균등 배분.
- **문장완성·영영풀이**처럼 내용이 긴 유형은 2단에서도 **전체 폭**으로 둡니다.

---



## 3. 밑줄(답 쓰는 자리)

- **왼쪽에 문제, 오른쪽에 밑줄**. 밑줄 길이는 일정하게 맞췄습니다.
- 뜻이 길면 왼쪽에서 **줄바꿈**하고, **밑줄은 마지막 줄 옆**에 옵니다.
- **(유)·(반) 표시는 밑줄 바로 왼쪽**에 붙입니다.
- **듣기 유형**(문제 글 없이 빈칸만)은 **번호 옆**에 밑줄이 옵니다.

**1단·2단 밑줄 차이 (현재 파일 기준)**

- **2단**: 밑줄이 문제 글에 바짝 붙어 있습니다(줄 간격을 넓혀도 밑줄이 아래로 벌어지지 않음).
- **1단**: 파생어·유의어 밑줄이 2단보다 조금 더 깁니다. 다만 **영영풀이처럼 문장이 긴 유형은 밑줄이 다음 줄로 내려가는 경우**가 있습니다.

---



## 4. 문항 유형별


| 유형            | 예시                              | 밑줄 위치                  |
| ------------- | ------------------------------- | ---------------------- |
| 듣고 쓰기         | `1. ____`                       | 번호 옆                   |
| 영단어→뜻 / 뜻→영단어 | `11. representation ____`       | 왼쪽 문제 / 오른쪽 밑줄         |
| 영영풀이          | `61. a new production … : ____` | 왼쪽 정의(길면 줄바꿈) / 오른쪽 밑줄 |
| 파생어·유의어       | `44. produce / [명사] 생산자 ____`   | 뜻 줄마다, 마지막 줄 옆         |
| 유의어·반의어       | `해외로 (유) ____`                  | (유)·(반) 뒤, 밑줄 앞        |
| 문장완성          | `The advertisement was ____ .`  | 문장 중간                  |
| 발문            | `※ 다음을 듣고 …`                    | 앞에 ※ 표시, 첫 문항과 붙어 다님   |


---



## 5. 여백·기타

- 페이지 여백: 위·아래 약 15mm, 좌·우 약 10mm.
- 발문 위 간격은 문항 사이 간격으로 처리해, 페이지·단 맨 위로 올라간 발문에는 불필요한 윗공백이 생기지 않습니다.
