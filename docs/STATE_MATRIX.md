# STATE_MATRIX.md — 시험지 다운로드(Export)

> 범위: 다운로드 실행 흐름의 상태·예외. 가이드 §14.1·§10.4(오류 상태 포함) 취지 반영.
> Export는 문서 저장 상태가 없는 무상태 변환이므로, 여기서는 **다운로드 트랜잭션 상태**를 기술한다.

## 1. 다운로드 실행 상태

| 상태 | 진입 조건 | UI/결과 | 다음 |
|---|---|---|---|
| idle | 페이지 로드 | 버튼 활성 | generating |
| generating | 버튼 클릭 | 버튼 disabled·라벨 '생성 중' | success / error |
| success | 파일 생성 완료 | 파일 다운로드(Blob 또는 data: URI) | idle |
| error | 생성 중 예외 | alert 메시지, 버튼 원복 | idle |

## 2. 오류(예외) 상태 — 실제 발생 사례 포함

| 코드/상황 | 원인 | 현재 처리 | 비고 |
|---|---|---|---|
| 템플릿 404 | 정본 템플릿 미탑재/경로 오류 | `alert('…템플릿을 못 찾음…HTTP 404')` | base64 내장으로 해소(fetch 미사용) |
| JSZip 미로드 | CDN 차단/오프라인 | `alert('JSZip을 못 불러왔습니다.')` | 오프라인 시 재현 |
| docx UMD 미로드 | CDN 차단 | DOCX 생성 실패 | 동상 |
| blob 스킴 거부 | `file://`에서 브라우저 정책 | `saveBlobCompat`가 data: URI로 우회 | 처리됨 |
| 데이터 없음 | groups 비어있음 | (미검증) | ⚠️ 방어 로직 미비 — 운영 시 보완 |

## 3. 표시 모드별 산출물 차이 (정상 상태 분기)

| 모드 | 문항 표기 | 정답 표기 |
|---|---|---|
| 문제 | 빈칸(밑줄) | 없음 |
| 정답 | 정답 채움 | O |
| 문제+정답 | 빈칸 + 정답 병기 | O |
| 문제(스펠링) | 첫 글자 힌트 | 없음 |

## 4. 상태 완전성 점검 (가이드 §19.2 "정상·로딩·빈값·오류·권한")

| 상태 | 구현 | 비고 |
|---|---|---|
| 정상 | O | 3포맷 생성 |
| 로딩(생성 중) | O | 버튼 disabled |
| 빈값 | △ | groups 빈 배열 방어 미비 |
| 오류 | O(부분) | alert 수준, 코드화 안 됨 |
| 권한 | ✗ | 권한 개념 없음(프로토타입) |
